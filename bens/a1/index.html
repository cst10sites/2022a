My older brother, Nicholas, is a mechanic.

I've also always had a general interest in computers from when I was little from the way they worked, how they are built, and the tens upon thousands, if not, hundreds of thousands of uses for them. So far, I have learned how to use Game Maker, create a website which contains text of different size, images, along with hyperlinks.
